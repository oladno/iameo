# Expense Tracker (Трекер расходов)

Автор: Ринат Бахтеев

## Описание программы

Это простая программа для ведения учёта расходов, написанная на Python с использованием библиотеки "tkinter". Она позволяет добавлять расходы с указанием суммы, категории и даты, а также фильтровать расходы по категории и диапазону дат. Все данные сохраняются в файл "meoakad.json", обеспечивая сохранность и загрузку данных при запуске программы.

## Как использовать

1. Запустите программу (обычно двойным кликом или через командную строку).
2. Введите сумму расхода, категорию и дату (по умолчанию текущая дата) в соответствующие поля.
3. Нажмите кнопку "Добавить расход" для сохранения нового расхода.
4. Для фильтрации расходов укажите категорию и/или диапазон дат, затем нажмите "Применить фильтр".
5. Чтобы посмотреть сумму текущего фильтра, нажмите кнопку "Посчитать сумму текущего фильтра".
6. Все расходы автоматически сохраняются в файл "meoakad.json", который загружится при следующем запуске.

## Примеры использования

### Добавление расхода:

- Ввести "150.00" в поле суммы.
- Ввести "Продукты" в категорию.
- Оставить дату по умолчанию или указать свою.
- Нажать "Добавить расход".

### Фильтрация расходов:

- Ввести "Продукты" в поле категории.
- Ввести диапазон дат: с "2025-05-05" по "2026-05-05".
- Нажать "Применить фильтр", затем отобразятся только расходы по этой категории за выбранный период.

### Подсчёт суммы по фильтру:

- После фильтрации нажать "Посчитать сумму текущего фильтра" и внизу появится сумма расходов по выбранным критериям.
